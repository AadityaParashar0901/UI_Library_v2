# UI Library v2
This is a UI Library made for qb64.  
It follows absolute positioning with nesting of components.  
_This library is made to be used mostly with mouse._

# Components
* Button
* Label
* Progress Bar
* Scroll Bar - Incomplete
* Slider
* Image
* Text Box - Incomplete
* List
* Spinner (Dropdown)
* Menu
* Radio Group
* Check Box
* Toggle Button
* Tabs -> Group and Page (Beta)

_These may be implemented in future._
* Dialog - Custom Dialog Component
* Dialog\_Message - Dialog Template with a Label
* Dialog\_Text - Dialog Template with a Text Box
* Dialog\_Image - Dialog Template with an Image
* Dialog\_List - Dialog Template with a List Box

# Features
* Coloring - Colors can be specified, and will change automatically with respect to mouse.
* Border - Every element has a border, border color, and it can be rounded.
* Response Value - Every element returns a response, with which the user can fire different events.
* Nesting - Most elements (Label, Dialog, Button, Tabs, etc.) allow nesting. Children Elements can be specified by lists. This library uses the [ListString](https://github.com/AadityaParashar0901/qb64_libraries/blob/master/dsa/ListString.bas) Library
